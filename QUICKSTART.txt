====================================
WYZECAR QUICK START GUIDE
====================================

OVERVIEW
--------
WYZECAR is a vision-based following robot using:
- DART-MX95 (main computer with ROS2)
- ESP32 (motor/servo controller via I2C)
- USB camera for computer vision
- L298N motor driver
- Servo for steering

Current Settings:
- Top Speed: 60% (adjustable in ros2/motor_controller.py)
- Steering Response: 0.6 max_angular_speed (more sensitive)
- Servo Slew Rate: 500°/s (fast steering)
- Deceleration: 300%/s (quick stops)

====================================
HARDWARE CONNECTIONS
====================================

ESP32 Connections:
- I2C: GPIO 21 (SDA), GPIO 22 (SCL) -> DART J6 pins
- Motors: ENA/IN1/IN2 (rear), ENB/IN3/IN4 (front)
- Servo: GPIO 33
- Power: 5V from USB

DART-MX95 Connections:
- I2C3: /dev/i2c-3 (J6 header)
- Camera: /dev/video13 (USB)
- WiFi: 192.168.5.181 (last known IP)

====================================
FINDING DART IP ADDRESS
====================================

Method 1 - Serial Console:
- Connect USB-C to DART's console port
- Open terminal: screen /dev/tty.usbserial* 115200
- Login and run: hostname -I

Method 2 - From Router:
- Check your router's DHCP client list
- Look for hostname "dartmx" or "wyzecar"

Method 3 - Network Scan:
- From your computer on same network:
  nmap -sn 192.168.5.0/24 | grep -B 2 "Variscite"
  or
  arp -a | grep dartmx

Method 4 - If Ethernet Connected:
- The DART usually gets a consistent IP
- Try previous IPs: 192.168.5.181, 192.168.5.183

====================================
WIFI CONFIGURATION
====================================

To configure WiFi on DART:

1. CONNECT VIA SERIAL OR ETHERNET FIRST
   screen /dev/tty.usbserial* 115200
   or
   ssh root@<ethernet_ip>

2. CONFIGURE WIFI CREDENTIALS
   Create/edit /etc/wpa_supplicant/wpa_supplicant.conf:
   
   network={
       ssid="YourNetworkName"
       psk="YourPassword"
   }

3. CONFIGURE INTERFACE
   Create /etc/network/interfaces.d/wlan0:
   
   auto wlan0
   iface wlan0 inet dhcp
       wpa-conf /etc/wpa_supplicant/wpa_supplicant.conf

4. ACTIVATE WIFI
   ifup wlan0
   
5. VERIFY CONNECTION
   ip addr show wlan0
   ping -c 2 google.com

6. MAKE IT PERMANENT
   systemctl enable networking

Note: WiFi will auto-connect on boot after configuration.

====================================
QUICK START STEPS
====================================

1. POWER ON
   - Connect ESP32 via USB (powers ESP32 + provides serial)
   - Power on DART-MX95
   - Power motor driver (12V battery)

2. UPLOAD ESP32 FIRMWARE (if needed)
   cd ~/Documents/GitHub/WYZECAR/firmware
   platformio run --target upload

3. ACCESS WYZECAR
   - Find IP first (see "FINDING DART IP ADDRESS" section above)
   - SSH: ssh root@<dart_ip>
   - Web Interface: http://<dart_ip>:8080

4. START/STOP WYZECAR
   On DART (via SSH):
   cd /home/wyzecar/WYZECAR
   ./wyzecar.sh start    # Start all services
   ./wyzecar.sh stop     # Stop all services
   ./wyzecar.sh logs     # View logs
   ./wyzecar.sh restart  # Restart services

5. UPDATE CODE
   On your computer:
   cd ~/Documents/GitHub/WYZECAR
   git add -A
   git commit -m "Your changes"
   git push

   On DART (via SSH):
   cd /home/wyzecar/WYZECAR
   git pull
   ./wyzecar.sh restart

====================================
WEB CONTROL INTERFACE
====================================

Access: http://192.168.5.181:8080

Controls:
- W/S: Forward/Backward (60% max speed)
- A/D: Left/Right steering
- Space: Emergency stop
- F: Toggle follow mode
- 1-9: Adjust follow distance

Features:
- 30 FPS video stream
- 50Hz control rate
- Real-time status display

====================================
ADJUSTING SETTINGS
====================================

1. SPEED SETTINGS
   Edit ros2/motor_controller.py:
   - max_speed_percent: 60 (current, range 0-100)
   - max_linear_speed: 0.6 (must match percentage)
   
   Edit ros2/web_viewer.py:
   - Update linear values to match (e.g., 0.6 for 60%)
   - Update display values to match percentage

2. STEERING SENSITIVITY
   - max_angular_speed: 0.6 (lower = more sensitive)
   - servo_slew_rate: 500 (higher = faster)

3. SERVO TRIM (if turns aren't equal)
   Option 1 - ROS2 parameter:
   ros2 param set /motor_controller servo_center_angle 87
   
   Option 2 - ESP32 firmware:
   Edit firmware/src/main.cpp:
   #define SERVO_CENTER_US 1480  // Adjust ±20

====================================
TESTING I2C COMMUNICATION
====================================

On DART:
i2cdetect -y 3              # Should show 42
i2cset -y 3 0x42 0x01 50 50 90 i  # Test command

====================================
COMMON ISSUES
====================================

1. Motors not responding:
   - Check I2C: i2cdetect -y 3
   - Check ESP32 serial monitor
   - Verify 12V power to motor driver

2. Video lag:
   - Currently optimized for 30 FPS
   - Check WiFi signal strength
   - Reduce JPEG quality if needed

3. Uneven turning:
   - Adjust servo_center_angle parameter
   - Check mechanical linkage

4. Car won't stop quickly:
   - deceleration_rate is set to 300%/s
   - Increase if needed
